# AFG FM録音IQデモ（実機なしで再生）

AFG3102 CH1から出した既知FM信号を、30dB減衰器2個とRTL-SDRを通してSpectrum Studioで収録したIQです。放送・会話の録音や、ソフトだけで生成したIQではありません。8.32秒、Fs1.024MS/s、受信中心32.256MHz。信号は32MHz FM・偏移±75kHz・1kHz音です。

## 配布ZIPから試す

1. ZIPをすべて書込み可能なフォルダーへ展開し、`start-studio.cmd`を起動。
2. 「プリセット」から **AFG_FM_32MHz_demo** を読み込む（VFO32MHz・WFM200kHz）。設定画面の×で閉じ、受信開始はまだ押さない。
3. 「保存データ」→ **demo_afg_fm_32mhz.sigmf-meta** の「IQ再生」。
4. 上部の **再生開始** を押す。Spectrum・Density・Waterfallを確認。
5. 音量を小さめにし、「音声をONにする」を押すと1kHz音を再生する。「現在：音声ON／OFF」は現在状態を示す。スピーカー開始は利用者操作が必要。
6. 終端で自動停止。もう一度はIQ再生位置sliderを左端へ戻して再生開始。「ライブへ戻る」で終了。

RTL-SDRの接続・WinUSB・AFGは再生には不要です。実機LIVE受信に必要な準備とは別です。VFOは32MHzのまま使うのが基本で、FMスペクトラムの最大ピークは搬送中心と一致しません。ピーク「選局」を試して周波数を動かした場合は、プリセットへ戻すかVFO32MHzへ戻してください。

## ソースから試す

このフォルダーの`.sigmf-meta`と`.sigmf-data`を**両方**アプリフォルダーの`data/recordings/`直下へ、`AFG_FM_32MHz_demo.json`を`data/settings/presets/`へコピーして上記手順を使う。同名の自分のファイルは上書きしない。GitHubのソースZIPだけでは実行ファイルは含まれないので、Windows配布ZIPまたは自分でビルドしたアプリを使う。

IQは未補正の取り込みbytesを保持。収録時のpath/serial/IP/PC名/正確な日時を共有用metadataへ含めず、sample起点を0へ付け替えています。元の私有収録は別途保持。

AFG設定50Ω/20mVpp/Offset0V・公称60dB減衰、受信gain49.6dB。実RFレベルの校正値ではありません。元IQのADC端値到達0、欠落0、収録WAVの1kHz主成分とPCM端値0を数値確認。音質や全PCのスピーカー動作を保証したものではありません。デモの再配布を目的にGitへ収録しており、個人の通常録音は含めません。

## アプリの終了

画面右上の「アプリ終了」→確認→終了表示の順。録音中は保存を確定して終了する。終了表示の後でブラウザーのタブを閉じる。
