# 既知の制約・未確認事項

2026-10-27時点の切り分けメモです。仕様は[SPEC.md](SPEC.md)、試験範囲は[VALIDATION.md](VALIDATION.md)を参照してください。以下の観測を全体の受入れ完了や測定性能の保証へ広げません。

- **中心ピークの発生箇所**：保存IQに残る複素平均から中心成分を説明できました。アプリ内の二重デコードや中心binだけの増幅は確認されていません。残留成分を生む物理段やドライバー内の処理は未特定です。信号源の出力OFF比較でもケーブル接続は残しており、受信機単体・終端条件の背景まで分離した結果ではありません。平均減算で消えることだけでは発生箇所を特定できません。
- **ノイズフロアの読み方**：Trace・MarkerはPSD×窓ENBW、雑音密度は電力/Hz、Channel Powerは帯域積分です。Fs・FFT点数・窓に伴う実効ENBWの差で床の表示値も変わります。床のdBFS値だけから受信雑音やS/Nの改善量を判断できません。
- **今回のゲイン比較**：一組の保存済み既知FM信号では、同じ検証キャリア・復調条件でゲイン20.7 dBと49.6 dBを比較し、1 kHz±20 Hz対その他100 Hz～15 kHzの簡易帯域電力比が約15 dBから約53 dBになりました。音量の個別正規化はしていません。この値は未校正の指標で、SNR・SINAD・感度の保証ではありません。屋外や強い複数信号での圧縮・相互変調は未確認で、最大ゲインの一般的な有利さは確認できていません。
- **低S/NでのOBW**：指定ROI内の雑音も積分するため、信号が弱いとOBWはROI幅へ近づきます。その値を変調信号だけの占有幅とは解釈できません。
- **v0.3.0のAFC**：VFOごとに手動ON/OFFでき、初期OFF、OFF時は補正0です。品質の連続確認と上限・速度・有効帯域制限を設けていますが、AM/FMの推定であり、複数局・非対称な変調・特殊な雑音で偏る可能性があります。中心DCは品質評価から除外し、低品質や両側雑音帯が不足する条件では更新を保留します。元IQ・PSDや名目周波数を補正せず、中心DC成分の修正機能ではありません。
- **音声補助と原音**：RFスケルチ、音声ゲイン、サンプルピークリミッター、既知境界のfadeは処理後経路へ作用します。大段差修理は明示境界だけで、任意chunk境界を修理対象にしません。リミッターの制限sample数・制限前過大入力と、保存PCMのclip数は別です。サンプル上限からD/A再構成後のピークやRFのS/N改善を保証しません。WAVの初期値は補助前demodで、processed選択時は記録した経路・設定・分割条件と統計も確認してください。
- **新版の検証段階**：受信音声補助はnativeの全対象82件と追加I/O境界1件、およびJavaScript49件の範囲です。配布版の保存実機IQを使うAPI/WAV13項目は確認済みですが、配布版GUI12項目＋受信・WAV読戻し12項目も成功しました。実機AFCのLOCK／帯域端GUI／聴感は未確認です。旧プリセットの不足項目は既定値で補いますが、旧版の画面・実機結果やPython参照の結果を新版の受入れへ読み替えません。
- **修正済みと実画面確認の区別**：狭いROIのトリガ積算と端bin、RBW自動選択のFFT128候補、GUI競合、長いパスからのDLL読込みは修正と回帰試験を行いました。v0.2.0の代表GUI23項目、v0.2.1のピークリセットGUI6項目＋読取りAPI継続6項目も確認済みです。全操作・録音中の実GUI・別PCまで検証した意味ではありません。
- **残る実環境の確認**：ノートPC・屋外・別PC、実際のスピーカー聴取、長時間連続運転と複数VFOの保証上限、実RF校正、USB物理抜去・再接続、実際の容量不足・権限差での保存終了は未確認です。短い有限収録や単体試験の成功は、これらの代替にはなりません。
