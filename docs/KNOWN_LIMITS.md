## v0.5.0の追加制約（検証中）

- v0.5.0の最終配布物・API・GUI・対応ソースの検証は準備中です。下記のv0.4.1以前の件数・観測値は当時の成果物に対応し、SSBや方式推定の合格や実RF性能を示しません。
- **SSBの基準位置**：VFOのHzは抑圧搬送波の基準で、通過帯域の中央ではありません。USBは基準の上側300 Hz〜300 Hz＋幅、LSBは下側300 Hz〜300 Hz＋幅です。低域300 Hz、幅の既定2.7 kHz・範囲1.0〜14.1 kHzは実装上の既定です。基準自身と通過帯域全体を取得有効帯域内に制限します。
- **SSBの同調とAFC**：AFCは適用外で、SSBへの変更時はOFFにします。ピークの帯域中央配置は、抑圧された搬送波の復元ではありません。手動で基準を微調整し、音声の高さを確認します。有限フィルターの遷移域があり、反対側波帯の抑圧・聴感・弱信号性能に実機保証値はありません。
- **方式推定は参考**：既定OFFの選択VFO用機能です。6〜250 kHz（既定200 kHz）の独立した観測幅を使い、中心DC補正前・復調前の原IQを評価します。復調結果を使う自己判定ではありませんが、原IQに残るDC、鏡像、混信、帯域不足、弱信号や過大入力は結果に影響します。
- **候補と保留**：AM/FM/USB/LSBを常に区別できる機能ではありません。無変調搬送波とSSBの単一音、変調休止や複数局など、有限観測から一意に識別できない条件があります。USB/LSBは明示された搬送波基準に対する候補です。基準不明・曖昧な信号は保留し、FM候補からのNFM/WFM選択は手動で行います。一致度を確率や正答率とは読みません。
- **設定と推定結果の寿命**：候補から方式・幅・VFO Hz・受信中心を自動変更しません。搬送波基準の確認は同調・選択VFO・入力・ソース変更、停止等で解除し、プリセットや再起動からtrueへ復元しません。結果も条件変更・欠落・シーク・推定OFFで無効にするため、停止前の候補を現在の信号の判定とは扱いません。
- **検証の限界**：合成IQや保存IQで確認する結果と、実RFのSSB聴感・反対側波帯抑圧・複数局や雑音下での推定精度は別です。低頻度の有限窓処理にも負荷があり、複数VFOの保証上限や長時間連続性能の確定には使えません。[操作と処理範囲](MODULATION.md)・[検証記録](VALIDATION.md)を参照してください。

## v0.4.1の範囲

- RF gain要求・driverのreported actual gain・表示のdB範囲は別です。AGC中やDirect入力では手動RF gainの効果を期待できず、tuner gainは離散値に丸められます。SpectrumのRef/RangeとDensityのdB上下限は独立です。
- 3画面は同じ周波数範囲を表示し、入力条件変更で旧frameを破棄します。heatmapの列集約/raster補間にはサブpixel程度の内部位置差が残る場合があります。点ごとの厳密一致やRF校正の保証ではありません。
- 周波数目盛りのdragと同じ軸の左右キーはSpan一定の中心変更です。VFOは絶対周波数を維持し、帯域外になるVFOはダイアログなしで自動停止します。この軸操作は停止を事前承認済みとして扱います。一般手入力のD24承認／取消と録音lockは維持し、保存IQの受信中心は変更できません。
- 新規VFOは追加操作の実行時点の最新中心へ配置して、そのVFOを選択します。基本WFM/200 kHzで、有効帯域・RF 0 Hz以上のため帯域を縮める場合があります。中心10 kHzでは最大20 kHzとなり、配置できてもFM放送の完全復調は保証しません。既存VFOの周波数や設定は追加操作で変更しません。
- 「アプリ終了」は正常終了を要求し、記録を確定してserverを終えます。未適用の入力は適用しません。成功後にこのブラウザーのタブを閉じます。単にタブを閉じてもserverの終了にはなりません。
- clean Windows／別PC／屋外／長時間／実スピーカー聴感と全RF帯域特性は引続き未検証です。

# 既知の制約・未確認事項

2026-10-27時点の切り分けメモです。仕様は[SPEC.md](SPEC.md)、試験範囲は[VALIDATION.md](VALIDATION.md)を参照してください。以下の観測を全体の受入れ完了や測定性能の保証へ広げません。

- **中心成分と補正の意味**：保存IQの複素平均から中心成分を説明できますが、その物理的な発生段は一意に特定していません。初回のモード遷移が後続設定を上書きする経路には初期化順序で対処しますが、中心成分の発生原因すべてを修理するものではありません。v0.4.0の公称20 Hz一極DC追従減算は受信用の処理経路だけへ適用し、原IQは保持します。平均減算で消えることだけを原因特定やRFのS/N改善とはしません。
- **中心の実信号への影響**：中心DCと実キャリアを識別して選別する処理ではありません。AM局を中心に置くと搬送波まで抑え、包絡復調が崩れる場合があります。OFF比較か、受信中心を局からずらしてVFOを局へ合わせる運用を使ってください。中心付近の信号、遅い変調、断続入力の振幅・位相や過渡にも影響します。RF感度／S/Nの改善ではなく、適用中は絶対レベル校正表示を使えません。
- **補正の初期化・記録・再生**：初回有限ブロックの平均を使うため、ブロック長と開始位置に依存します。連続中は状態を保持しますが、開始・停止・欠落・シークでは初期化します。保存するIQは未補正なので、同じ再生位置の処理状態まで収録時とbit一致する保証はありません。WAVの「復調音」は音声補助前でも中心補正と同調処理を反映します。
- **適用機種とDirect Sampling**：現実装は要求ONかつチューナー経路へ適用し、Direct Sampling I/Qと低Fs再生は迂回します。入力経路がメタデータから不明な場合は要求設定からの推定です。別機種での共通性、C ABI／互換ドライバーDLL、配布ライセンスは未確定です。
- **v0.4.0の確認範囲**：Native108件・JS66件・release DSP probe211件・保存IQ API19項目・実行中設定境界24項目・DEMO実GUI12項目と、50Ω終端の有限受信・ZIP／自己診断を確認しました。[VALIDATION.md](VALIDATION.md) に条件を記載しています。実RF全周波数域・感度／SINAD／SFDR／alias／AGC実応答は未測定で、別PC・屋外・実聴・長時間運転は未検証です。
- **ノイズフロアの読み方**：Trace・MarkerはPSD×窓ENBW、雑音密度は電力/Hz、Channel Powerは帯域積分です。Fs・FFT点数・窓に伴う実効ENBWの差で床の表示値も変わります。床のdBFS値だけから受信雑音やS/Nの改善量を判断できません。
- **今回のゲイン比較**：一組の保存済み既知FM信号では、同じ検証キャリア・復調条件でゲイン20.7 dBと49.6 dBを比較し、1 kHz±20 Hz対その他100 Hz～15 kHzの簡易帯域電力比が約15 dBから約53 dBになりました。音量の個別正規化はしていません。この値は未校正の指標で、SNR・SINAD・感度の保証ではありません。屋外や強い複数信号での圧縮・相互変調は未確認で、最大ゲインの一般的な有利さは確認できていません。
- **低S/NでのOBW**：指定ROI内の雑音も積分するため、信号が弱いとOBWはROI幅へ近づきます。その値を変調信号だけの占有幅とは解釈できません。
- **ナイキスト端のOBW**：共有解析器へ全ナイキストROIを与えた場合、端binの電力は周期境界の両端へ分けて積分します。CPは全電力を保持しますが、OBWは直線の周波数軸に沿うため、端を跨ぐ単一成分でも広い幅になり得ます。通常UIの有効帯域端と、解析器の全ナイキスト端を混同しないでください。
- **v0.3.0のAFC**：VFOごとに手動ON/OFFでき、初期OFF、OFF時は補正0です。品質の連続確認と上限・速度・有効帯域制限を設けていますが、AM/FMの推定であり、複数局・非対称な変調・特殊な雑音で偏る可能性があります。中心DCは品質評価から除外し、低品質や両側雑音帯が不足する条件では更新を保留します。元IQ・PSDや名目周波数を補正せず、中心DC成分の修正機能ではありません。
- **音声補助と原音**：RFスケルチ、音声ゲイン、サンプルピークリミッター、既知境界のfadeは処理後経路へ作用します。大段差修理は明示境界だけで、任意chunk境界を修理対象にしません。リミッターの制限sample数・制限前過大入力と、保存PCMのclip数は別です。サンプル上限からD/A再構成後のピークやRFのS/N改善を保証しません。WAVの初期値は補助前demodで、processed選択時は記録した経路・設定・分割条件と統計も確認してください。
