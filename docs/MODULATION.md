# SSB復調と変調方式の参考推定

## USB／LSBを聴く

VFOの方式からUSBまたはLSBを選び、適用します。既定の幅は2.7 kHzです。VFOの周波数は抑圧された搬送波の基準位置で、信号の帯域中央とは異なります。

| 方式 | 基準f0に対するRF通過帯域 | 既定幅2.7 kHzの場合 |
|---|---|---|
| USB | f0+300 Hz〜f0+300 Hz+幅 | f0+300〜f0+3000 Hz |
| LSB | f0−300 Hz−幅〜f0−300 Hz | f0−3000〜f0−300 Hz |
| AM／NFM／WFM | f0−幅/2〜f0+幅/2 | 既存の対称帯域 |

SSBでは基準周波数を少し動かすと音声の高さも変わります。ピークの「帯域内に配置」は信号をフィルター内に置く補助です。搬送波位置を特定する機能ではなく、配置後は基準を微調整します。画面の外側の帯域端をドラッグすると、基準を保って幅を変更できます。受信中心を動かしても既存VFOの絶対周波数は追従しません。

現在のAFCはAM/FM用で、SSBには適用しません。USB／LSBへの切替ではAFCをOFFにし、その状態を表示します。SSBの復調音も個別WAVへ保存でき、原IQの保存バイト列は変えません。

工学上の既定は低域300 Hz、幅1000〜14100 Hz、音声32 kHzです。フィルター端には遷移域があり、名目端を理想的な矩形通過帯域とは扱いません。RF感度、音質、反対側波帯抑圧の実機保証値ではありません。

## 方式を参考推定する

推定は既定OFFです。選択VFOの周辺IQを、現在の復調方式とは独立に観測します。推定用の観測幅は復調用の幅と別に指定します。複数局が含まれる場合は狭め、FMなど広い信号は全体が収まる幅を使います。

信号はVFO基準の±観測幅/2で評価し、その外側で雑音と比較します。比較帯域も含めた±観測幅が有効取得帯域に収まる条件が必要です。端に近いVFOでは観測幅を狭めるか、受信中心を調整します。観測幅に受信中心を含む場合は、残留DCと信号を区別できないため保留します。

表示されるものは候補と観測根拠です。設定した方式、幅、VFO周波数、受信中心を自動変更しません。利用者が結果を見て手動で方式を選びます。FMの候補だけではNFM／WFMのどちらが適切か断定できない場合があります。

USB／LSBの区別には搬送波基準が必要です。基準を利用者が指定した場合も「VFO基準の候補」として扱います。基準不明、弱信号、無変調、雑音、混信、観測帯域の不足、欠落、中心DCの影響が疑われる場合は判定を保留します。SSBの単一音と無変調の単一搬送波など、観測だけで区別できない信号があります。

停止、入力・選択VFO・同調変更、欠落、シーク、推定OFFでは古い結果を無効にします。推定は有限窓・低頻度更新で、機械学習モデルや追加ダウンロードを必要としません。一致度は校正済み確率や正答率を意味しません。

## 検証の扱い

合成IQでの方式別応答、雑音・曖昧な信号の保留、保存IQ再生・WAV出力とUIを検証します。合成信号での成功を、実RFの方式判別精度やSSB聴感の保証へ一般化しません。実施結果と残る条件は[検証範囲](VALIDATION.md)を参照してください。

設計上の参考資料：[University of VictoriaのSSB受信実験](https://mistic-lab.github.io/ece-communications-labs/ece350/lab2/SSB-receiver)、[GNU RadioのSSB例](https://wiki.gnuradio.org/index.php?title=Simulation_example%3A_Single_Sideband_transceiver)。実装コードは本プロジェクトで独立に作成しています。
