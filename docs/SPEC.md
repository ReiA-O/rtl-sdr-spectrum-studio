# 実装仕様と制約

## 対象

Windows 10/11 x64、RTL-SDR Blog V3を最初の実機対象とする開発版です。AM/FMのIQ取得・復調・保存を中心に、一度に連続受信できる帯域を観測します。広帯域掃引、他機種、FMステレオ/RDS、弱信号処理の追加は現在の完成条件に含めません。

## 受信とVFO

- 入力の中心周波数、サンプルレート、ゲイン、AGC、PPM、受信モードを設定します。中心・Span・RBW/FFT・Ref Levelは個別に操作します。
- 設定可能な中心は10 kHz～1.766 GHz、Fsは1.024／1.536／2.048／2.4 MS/sです。今回固定したドライバーでは明示チューナー指定を24 MHz以上、明示Direct I/Qを28.8 MHz以下に制限し、矛盾する指定を受信停止より前に拒否します。数値の受理は実RFの感度・帯域・像妨害性能を保証しません。
- 同一受信帯域内へ複数VFOを追加し、AM/NFM/WFMを独立処理します。スピーカーへは選択中の1局を出力し、各VFOのWAVは独立保存します。
- 有効帯域外へのVFO移動を拒否し、中心周波数を自動追従させません。一般手入力の中心変更で無効化が必要なVFOは影響を表示し、確認後に変更します。周波数軸ドラッグ／同軸キー操作では帯域外VFOの停止を事前承認済みとして扱い、確認なしで停止し、既存VFOの絶対周波数は変えません。新規VFOは追加処理時の最新中心へ配置して選択します。
- 過負荷時は選択VFOを優先し、他のVFOを停止します。保証できる同時VFO数は未確定です。
- AMはキャリア正規化包絡、FMは位相差復調です。WFMは公称偏移75 kHz、50 μs de-emphasis、固定音声ゲイン0.5。AM/NFMの固定ゲインは1。音声サンプルレート32 kHz、モノラルです。これらは実装時の暫定値で、校正性能の保証ではありません。
- 復調器内で出力を隠れてクリップせず、PCM保存側で飽和を計数します。入力のデジタル端値がないことだけでアナログ圧縮を否定しません。

## v0.3.0の受信・音声補助

- 各VFOのAFCは手動でON/OFFを切り替え、初期値はOFFです。ON時も受信機の中心周波数とVFOの名目周波数は変更せず、連続位相のデジタルNCO補正量を別に示します。OFF時は補正量を0へ戻して名目周波数で受信し、元IQ・解析PSD・全体のサンプル時計を初期化しません。
- AFCは帯域内電力と両側雑音帯から品質を推定し、連続した信頼期間を経て、設定上限・有効帯域の余裕・補正速度の制限内で更新します。受信中心のDC付近は品質評価から除外し、低品質・DCのみ・雑音側帯不足・有効帯域端では更新を保留します。これはCRC等で確証された捕捉ではなく、AM/FM用の保守的な推定です。再開・入力欠落・手動の局変更では追従状態を初期化します。
- 既存のNCOとFFT-FIRによる狭帯域抽出を再利用します。AFCと復調後の音声補助は元IQや共通FFTのPSDを変更しません。v0.4.0の中心DC補正は、これらより前に置く独立した共通処理です。
- 復調後の独立した音声経路へ、RF電力に基づくスケルチ、hysteresis／hang、音声ゲイン、サンプルピークリミッターを適用します。スケルチとAFCは初期OFF、音声ゲインは0 dB、リミッターは初期ONです。静かな音声への不要な増幅は行わず、制限前の過大入力と制限sample数を別に数えます。
- 既知の開始・欠落・スケルチ再開には短いfadeを用います。大段差の短い修理は明示的に分かる境界だけを対象とし、任意の処理chunk境界や正当な高周波音声をクリックとみなして修理しません。処理状態はsample数で進め、通常の設定同値更新で消しません。
- スピーカーは処理後音声です。WAVは補助前の`demod`が初期値で、VFOごとに`processed`も選べます。補助設定や保存経路の実変更はWAVを分割し、経路・設定・過大入力／制限／mute／欠落等の統計を記録します。同値更新は分割しません。旧プリセットで補助設定がない場合は上記初期値を補い、受信・Arm・録音を自動開始しません。
- 時間定数・品質閾値・fade・リミッター上限などは実装時の暫定値です。サンプルピークの制限はD/A再構成後のピーク保証ではなく、実RFのS/N・感度改善を意味しません。AFCと音声補助自体には中心DC除去の役割を持たせません。

## v0.4.0の中心DC補正とピーク選局

- 独立I/Qの一極平均追従減算を、複素IQの処理用バッファに適用します。公称コーナー20 Hz、既定ON、手動OFFに対応します。描画の中心binだけを隠す方式ではありません。
- 同じ補正後IQからSpectrum・Density・Waterfall、Marker／ピーク、Channel Power／OBW、トリガ判定、VFO復調を処理します。元のcu8バイト列は変更せず、プリトリガバッファとSigMFは原IQを保持します。WAVには補正後の復調経路が反映されます。
- 最初の有限ブロックのI/Q平均で初期化し、以後は連続状態を保持します。開始・停止・入力変更・欠落・シークで初期化します。再生開始位置や最初のブロック長により開始部は変わり得ます。
- Arm・IQ保存・WAV録音中はON/OFFの実変更を拒否します。同値更新では履歴を消去しません。実変更時はFFT途中・Max／Min／Average・Density・Waterfall・音声をリセットし、旧条件のframeを棄却します。
- 実際の入力経路がDirect Sampling I/Qの場合と、有限かつ40 Hzより大きいFsを満たさない再生では適用しません。停止中・OFF・適用外・適用中を区別し、保存IQの入力モード情報と要求設定からの推定も区別します。
- 中心の実キャリアや遅い変調も影響を受けます。AM局を中心に置くと搬送波を抑えて包絡復調が崩れる場合があるため、OFF比較か、受信中心を局からずらしてVFOを局へ合わせる運用を使います。RF感度／S/N改善ではありません。中心付近を校正した絶対測定とは扱わず、補正適用中は絶対レベル表示を無効化します。原IQには補正を施さず、方式・要求／適用状態・入力経路・記録経路をメタデータへ残します。
- `set_frontend`は`frontend.dc_reject_enabled`の真偽値を受け付け、未知キーと異なる型を拒否します。旧プリセットに項目がない場合はONを補います。設定復元で受信・Arm・録音は開始しません。
- ピークのVFO同調操作は選択VFOだけを移動します。名目中心は保持し、対象VFOの存在・有効状態と帯域境界を再確認します。未適用のVFO編集がある場合は同調を保留します。
- RTL-SDR Blogドライバーで初期チューナー切替が帯域等の設定を上書きしないよう、希望する中心と入力モードを先に確定してからFs等を設定します。要求モードとの不一致は受信開始に成功した扱いにしません。

式、API、初期化、原IQと処理IQの境界は [FRONTEND.md](FRONTEND.md) を参照してください。実機の発生原因を修理したことや、任意の機種に対応する共通ドライバーの完成を意味しません。

## 表示・測定

- Spectrumを最大に配置し、密度表示・Waterfall・復調パネルを同時表示します。FFT条件は共通、表示処理は独立です。
- FFTは128～32768点。RBW指定は窓のENBWから実現可能なFFTサイズを選び、実効bin幅・ENBWを示します。手動FFTも使えます。
- TraceはLive/Max Hold/Min Hold/平均、表示検波はSample/Positive Peak/Negative Peak/RMSです。表示用の縮約と測定用PSDを区別します。
- 「ピークリセット」はMax Hold／Min Hold／平均を最新有効Live PSDへ揃えて再集計します。入力・FFT・表示条件、密度・Waterfall、Marker位置、VFO、トリガ／プリバッファ、IQ/WAVとサンプル時計は維持します。共有平均PSD由来の平均Channel Powerも新しい平均履歴へ追従します。
- 密度は全有効FFTフレームを集計し、ヒット数／出現率、累積／Persistenceを切り替えます。Persistenceは指数減衰／時間窓／OFF／Infinite、指数減衰の指定は半減期／時定数／フレーム数に対応します。
- Densityの縦軸上限／下限はSpectrumのRef／Rangeと独立して手動設定します。範囲変更は密度の履歴・母数だけを再集計し、全体FFT数・Spectrum保持・Waterfall・時計・記録を維持します。画面の校正単位は編集時に解釈し、内部へは正本dBFSで渡します。
- FFT・窓・入力など解析条件の変更で密度履歴をクリアして通知します。時間窓の保持には容量上限があり、実効保持秒・保持FFT数・上限・短縮警告を表示します。
- 自動マーカーはピーク上位へ配置します。独立したユーザーマーカーは追加・選択・移動、最大／左隣／右隣ピーク、Δ表示に対応し、自動マーカーと併用できます。
- Channel PowerとOBWには独立測定帯域を指定でき、VFO連動も可能です。境界binは測定帯域との重なり幅で積分します。OBWは指定帯域内の信号と雑音を含む電力分布から計算します。
- 全ナイキスト範囲を解析するときは、FFT端binの積分セルを周期的に両端へ分け、CPと平均CPを取りこぼさず積分します。OBWは昇順の直線周波数軸で計算するため、同じ周期binの電力が両端へ分かれると両端間を含む広い幅になり得ます。周期軸上の最短幅を求める方式ではありません。
- 内部PSDは二側帯の線形電力/Hz。複素振幅1を電力1=0 dBFSとします。Trace・MarkerはPSD×窓ENBWのdBFS、CPはPSDの帯域積分です。校正プロファイルなしでdBm精度を主張しません。
- 原IQのバイト列や中心binの描画だけを置き換えません。中心補正ONでは処理用IQに追従減算を適用し、OFFでは残留複素DCが中心ピークとして表示される場合があります。

## IQ・トリガ・WAV

- IQはunsigned 8 bit interleaved I/Q（SigMF cu8）、表示時の正規化は`(byte-127.5)/127.5`です。原byte列を保存します。
- 基本レベルトリガはピーク／積算電力、One-Shot／Auto、秒単位のプリ／ポスト時間に対応します。再検出は同じ記録に統合し、後方時間を延長します。
- IQ保存中は中心・サンプルレートだけでなくゲイン・AGC・PPM・受信モード等の入力条件もロックします。中心補正はArm・IQ保存・WAV録音中にロックします。
- 欠落・中断・記録上限・例外をメタデータへ記録し、完了していない保存を成功扱いしません。再生は保存されたサンプル境界と欠落を保持します。
- WAVはVFO別、PCM16/24。中心・復調条件変更の影響は分割とメタデータへ反映します。

## 保存IQの再生と同梱AFGデモ

- 保存IQはSigMFの`cu8`、単一複素チャンネルを対象とし、`.sigmf-meta`と`.sigmf-data`を同じフォルダーへ置きます。`data/recordings/`直下の記録は「保存データ」一覧から「IQ再生」で開けます。再生開始・シーク・VFO再同調／再復調、停止、ライブへ戻る操作を持ち、LIVE受信とは排他です。
- WAVは復調後の音声保存用です。WAVから元のIQやRFスペクトラムを再解析する機能として扱いません。
- 同梱デモはAFG3102の32 MHz FM（偏移±75 kHz、1 kHz試験音）をStudioで取り込んだ8.32秒の実RF収録です。Fs1.024 MS/s、受信中心32.256 MHz、原IQはcu8・17,039,360 bytesです。純粋な合成IQ生成器のDEMO入力とは区別し、個人の通常受信記録や放送番組は入れません。
- 再生用`AFG_FM_32MHz_demo`プリセットはVFO32 MHz・WFM200 kHz、手動FFT4096点・実効RBW375 Hzです。FMの最強ピークがキャリア中心とは限らないため、最初の再生はプリセットの名目周波数を使います。既存の測定用初期プリセットを変更しません。
- 「プリセット」でデモ設定を読み込んだ後、設定画面右上の×で閉じます。「保存データ」→デモIQの「IQ再生」→「再生開始」へ進み、音声は利用者操作でONにします。EOFで停止し、再生位置スライダーを先頭へ戻して再生できます。
- 公開metadataは再生に必要な形式・Fs・中心・入力モード等から構成し、機器IP／シリアル・個人名・絶対パス・正確な収録日時を除外しました。元のIQバイト列を保持し、sample起点のみmetadataで0へ揃えています。承認した4ファイルをmanifestの正確なサイズ・SHA256で特定して同梱します。
- デモ同梱版はexeを更新しないv0.4.0の配布構成違いです。最終ZIPの再生14項目は受信DLLを無効化した模擬状態で確認しました。実GUI9項目は先行デモ候補で確認し、最終版の差は案内文だけです。実USB抜去・清浄な別PC・スピーカー聴感の合格には拡張しません。

## 保存と実行

起動時は受信・Arm・録音を自動開始せず、設定だけを復元します。UIはexe内蔵、通常ブラウザーを利用し、127.0.0.1で待受けます。設定と録音は指定ルートの`data/`内です。最初の機器設定は利用者が確認して受信開始を押します。

実装済み機能は、全体の性能・RF校正・ユーザー受入れ完了を意味しません。[VALIDATION.md](VALIDATION.md)を参照してください。
