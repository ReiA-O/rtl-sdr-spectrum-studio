# 実装仕様と制約

## 対象

Windows 10/11 x64、RTL-SDR Blog V3を最初の実機対象とする開発版です。AM/FMのIQ取得・復調・保存を中心に、一度に連続受信できる帯域を観測します。広帯域掃引、他機種、FMステレオ/RDS、弱信号処理の追加は現在の完成条件に含めません。

## 受信とVFO

- 入力の中心周波数、サンプルレート、ゲイン、AGC、PPM、受信モードを設定します。中心・Span・RBW/FFT・Ref Levelは個別に操作します。
- 同一受信帯域内へ複数VFOを追加し、AM/NFM/WFMを独立処理します。スピーカーへは選択中の1局を出力し、各VFOのWAVは独立保存します。
- 有効帯域外へのVFO移動を拒否し、中心周波数を自動追従させません。手動中心変更で無効化が必要なVFOは影響を表示し、確認後に変更します。
- 過負荷時は選択VFOを優先し、他のVFOを停止します。保証できる同時VFO数は未確定です。
- AMはキャリア正規化包絡、FMは位相差復調です。WFMは公称偏移75 kHz、50 μs de-emphasis、固定音声ゲイン0.5。AM/NFMの固定ゲインは1。音声サンプルレート32 kHz、モノラルです。これらは実装時の暫定値で、校正性能の保証ではありません。
- 復調器内で出力を隠れてクリップせず、PCM保存側で飽和を計数します。入力のデジタル端値がないことだけでアナログ圧縮を否定しません。

## 表示・測定

- Spectrumを最大に配置し、密度表示・Waterfall・復調パネルを同時表示します。FFT条件は共通、表示処理は独立です。
- FFTは128～32768点。RBW指定は窓のENBWから実現可能なFFTサイズを選び、実効bin幅・ENBWを示します。手動FFTも使えます。
- TraceはLive/Max Hold/Min Hold/平均、表示検波はSample/Positive Peak/Negative Peak/RMSです。表示用の縮約と測定用PSDを区別します。
- 密度は全有効FFTフレームを集計し、ヒット数／出現率、累積／Persistenceを切り替えます。Persistenceは指数減衰／時間窓／OFF／Infinite、指数減衰の指定は半減期／時定数／フレーム数に対応します。
- FFT・窓・入力など解析条件の変更で密度履歴をクリアして通知します。時間窓の保持には容量上限があり、実効保持秒・保持FFT数・上限・短縮警告を表示します。
- 自動マーカーはピーク上位へ配置します。独立したユーザーマーカーは追加・選択・移動、最大／左隣／右隣ピーク、Δ表示に対応し、自動マーカーと併用できます。
- Channel PowerとOBWには独立測定帯域を指定でき、VFO連動も可能です。境界binは測定帯域との重なり幅で積分します。OBWは指定帯域内の信号と雑音を含む電力分布から計算します。
- 内部PSDは二側帯の線形電力/Hz。複素振幅1を電力1=0 dBFSとします。Trace・MarkerはPSD×窓ENBWのdBFS、CPはPSDの帯域積分です。校正プロファイルなしでdBm精度を主張しません。
- 原IQの平均値推定減算や中心binの隠蔽は行いません。残留複素DCが中心ピークとして表示される場合があります。

## IQ・トリガ・WAV

- IQはunsigned 8 bit interleaved I/Q（SigMF cu8）、表示時の正規化は`(byte-127.5)/127.5`です。原byte列を保存します。
- 基本レベルトリガはピーク／積算電力、One-Shot／Auto、秒単位のプリ／ポスト時間に対応します。再検出は同じ記録に統合し、後方時間を延長します。
- IQ保存中は中心・サンプルレートだけでなくゲイン・AGC・PPM・受信モード等の入力条件もロックします。
- 欠落・中断・記録上限・例外をメタデータへ記録し、完了していない保存を成功扱いしません。再生は保存されたサンプル境界と欠落を保持します。
- WAVはVFO別、PCM16/24。中心・復調条件変更の影響は分割とメタデータへ反映します。

## 保存と実行

起動時は受信・Arm・録音を自動開始せず、設定だけを復元します。UIはexe内蔵、通常ブラウザーを利用し、127.0.0.1で待受けます。設定と録音は指定ルートの`data/`内です。最初の機器設定は利用者が確認して受信開始を押します。

実装済み機能は、全体の性能・RF校正・ユーザー受入れ完了を意味しません。[VALIDATION.md](VALIDATION.md)を参照してください。
