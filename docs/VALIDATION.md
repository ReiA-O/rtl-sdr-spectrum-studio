# 検証範囲

2026-10-27時点の開発記録を、個人データ・機器識別情報を除いて要約しています。原IQ、実機接続先、シリアル番号、私的な検証ログや画面は同梱しません。公開準備用の別ソースフォルダーでもRust50件・JavaScript16件・Python32件を再実行して合格しました。別PCや新しいclone環境全体の動作保証とは区別します。

| 対象 | 確認済みの範囲 | 限界・未確認 |
|---|---|---|
| Rust本体 | 初期段階40項目から追加し、現ソースの最終記録はlibrary 46＋main 4＝50項目合格 | 明示IQ fixture 1件は通常ignored。OS・機器・全機能の組合せ網羅ではない |
| Python参照 | 32項目合格 | 数値参照用。Rustの実装と性能・FFT精度が完全一致する保証ではない |
| JavaScript | 最新状態境界16項目合格（以前13項目から追加） | pure JavaScriptのテスト。ブラウザー表示・クリック・音声再生の検証ではない |
| 実機の基本経路 | 13項目の操作・IQ/WAV保存・既知1 kHz復調等を確認 | 一部IQ再生は合成入力由来。全体の感度・音質・校正合格ではない |
| ユーザーマーカー | 保存実機IQでEngine API経由の7項目を確認。独立f64 FFTと周波数・レベルを照合 | 保存データでのオフライン検証。新LIVE受信や実画面操作の検証ではない |
| 受信条件境界 | ゲイン両端・帯域端付近・サンプルレート等8条件の有限収録と解析 | 設定値・雑音・実効RBWの影響を含む。RF入力レベルは未校正 |
| 配布構成 | remap release、Windows x64 PE依存、内蔵UI、全ZIP hash・個人文字列検査、日本語と空白のある別フォルダーへ展開して内蔵UI／package内DLL読込み診断成功 | 診断はサーバー・受信・録音を開始しない。未署名の開発版で、別PC／実GUIとは区別 |
| 画面・持出し | 旧版では実Chromeの代表表示と操作を確認 | 0.2.0の最新UIを実画面で一連操作する試験、ノートPC、屋外、清浄な別PC、スピーカー聴取は未確認 |

中心追従ピークは、受信IQの複素平均と背景で定量的に説明できることを確認しています。発振源出力ON/OFF比較でも中心成分が残りましたが、ADC・ベースバンド・DDC・ドライバー処理・中点規約の物理的な発生箇所を一意に特定したわけではありません。平均値を引いて消えることだけを物理原因の証明やS/N改善としません。

GainやFsの比較でdBFS値は変わります。Fs 2.4 MS/sの実効ENBWが439.45 Hz、他の比較条件では750 Hzとなったため、雑音密度はdBFS/Hzで区別しました。低S/NのOBWは雑音で測定帯域幅へ近づき、変調波固有の幅とは解釈できません。

実RF入力の絶対電力、減衰器の実特性、周波数基準、校正dBm、感度、SINAD、捕捉率、保証VFO数、長時間連続運転は未確定です。初期要件全体の受入れ合格や測定器同等性能とは扱いません。

再実行する通常テストはREADMEの3コマンドを使います。保存実機IQを使う追加テストには、利用者が自分のデータと必要な比較／プリセットJSONを明示指定する必要があります。原データを公開する必要はありません。
